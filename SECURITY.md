# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Cadence, please report it responsibly:

- **Preferred:** [GitHub Security Advisories](https://github.com/abstractonion/cadence/security/advisories/new) (private report to maintainers)
- **Alternative:** email calebuzu@gmail.com

Please do **not** open a public GitHub issue for undisclosed security problems.

Include enough detail for us to reproduce and assess the issue (affected files, steps, impact). We will acknowledge receipt and work on a fix; we may ask for more information.

## Scope

This policy covers the Cadence repository: plugin manifests, sync scripts, rules/skills content, and install documentation. It does not cover third-party runtimes (Cursor, Claude Code, etc.) or downstream projects that consume Cadence rules.

## Disclosure

We aim to coordinate disclosure after a fix is available. We appreciate responsible reports and will credit reporters when they wish.
