# Privacy Policy

**Last updated:** 2026-05-26

## Who we are

Cadence is an open-source plugin maintained by [abstractonion](https://github.com/abstractonion) and [jerry-chibuife](https://github.com/Jerry-Chibuife) of [mbarihaus](https://github.com/mbarihaus). The source repository is at [github.com/abstractonion/cadence](https://github.com/abstractonion/cadence).

## What Cadence is

Cadence ships static rule and skill files that are installed locally in your editor or agent runtime. It does not run a backend service operated by the plugin author for plugin functionality. There is no Cadence account, login, or cloud API required to use the plugin.

## What we do not collect

Cadence itself does **not**:

- collect analytics or usage telemetry
- track how you use the plugin
- upload your code, chat, or project data to a Cadence-operated server
- require you to create an account with the plugin author

The plugin content is read from your local install (or from GitHub when you clone or install from the repository).

## What third parties may process

When you install or use Cadence, other services involved in that process have their own privacy policies and terms:

- **GitHub** — Installing or cloning from [github.com/abstractonion/cadence](https://github.com/abstractonion/cadence) is subject to [GitHub's terms and privacy policy](https://docs.github.com/en/site-policy).
- **Cursor** — If you install via Cursor's plugin flow, Cursor's product terms and privacy policy apply to that installation and to how Cursor runs agents in your environment.
- **Claude Code / Anthropic** — If you install via Claude Code's marketplace, Anthropic's terms and privacy policy apply to that product and its agent runtime.
- **Model providers** — When an agent runtime uses Cadence rules or skills, it may send chat messages and code context to the model provider configured in that product (for example Anthropic, OpenAI, or another provider you chose). That data flow is controlled by the host product and your settings, not by Cadence.

Cadence does not control and is not responsible for data handling by these third parties.
