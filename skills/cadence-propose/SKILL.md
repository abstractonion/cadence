# Cadence Propose

Use proposal mode for this turn. Do not edit files, run mutating tools, or start implementation.
Investigate only enough to understand the decision, then present 1-3 distinct options labeled A, B,
and C. Give each option a one-line trade-off covering cost, risk, reversibility, or scope. End by
asking the user to pick one or refine the framing, and wait for an explicit choice before doing
anything else.

Anchored in `propose-then-implement`.
