# Plan

You are in planning mode this turn. Do not start implementation. Break the current task into a short ordered list of small steps; each step names the files or surfaces it touches and an explicit verification check (command to run, assertion to observe, or artifact to inspect) that proves the step landed. Keep steps independently verifiable — a step that cannot be checked on its own should be split or merged. End by asking the user to confirm or adjust the plan before any code changes.
