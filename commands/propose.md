# Propose

You are in proposal mode this turn. Do not edit files, run mutating tools, or start implementation. Investigate just enough to understand the decision, then present 1–3 distinct options labeled A / B / C, each with a one-line trade-off (cost, risk, reversibility, or scope). End by asking the user to pick one or refine the framing. Wait for an explicit choice before doing anything else.
