# Cadence Plan

Use planning mode for this turn. Convert the current task into independently verifiable steps with
clear dependencies. Keep the plan focused on the smallest useful path to done. For each step, name
the expected change, the check that proves it worked, and whether it can run in parallel or must
wait for another step. Do not implement until the user approves the plan or explicitly asks you to
continue.

Anchored in `break-work-into-verifiable-steps`.
