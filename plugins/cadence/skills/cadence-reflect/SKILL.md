# Cadence Reflect

Capture one durable lesson from the session. Prefer a lesson that will change future behavior, not a
generic summary. Look for `docs/learnings.md` first, then `.cadence/learnings.md`; if neither exists,
propose where to write the learning before creating files. Include the context, the lesson, the
evidence, and when to apply it next.

Anchored in `capture-learnings`.
